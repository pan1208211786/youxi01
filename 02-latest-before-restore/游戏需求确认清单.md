# 《遗迹小径》需求确认清单

这份文档记录目前已经确认的游戏方向。以后继续开发时，以这里的内容为准，避免又回到旧版推箱子思路。

## 1. 游戏基本信息

- 游戏名称：`遗迹小径`
- 制作技术：HTML + JavaScript + Phaser.js
- 运行方式：在电脑浏览器中打开
- 主要操作设备：电脑键盘
- 游戏类型：俯视角、全场景自由探索冒险
- 整体画风：卡通森林遗迹风格
- 关卡推进方式：线性闯关，通关后解锁下一关
- 关卡地图：每一关都必须有不同的地图轮廓、墙体分布和探索路线
- 存档方式：自动保存，可以继续游戏
- 已通关关卡：可以在关卡选择页面重新挑战

## 2. 主角与故事

- 主角：背着小包的探险小女孩
- 故事表达：保持轻量，不做大量文字剧情
- 碎片规则：每关都有一个碎片，必须收集本关碎片才能完成通关
- 首页显示：主菜单底部显示当前已收集碎片数量

## 3. 新核心玩法方向

- 不再做推箱子玩法。
- 不再使用一格一格移动的简单移动方式。
- 小女孩应在完整场景中连续自由移动。
- 当前取消地图黑色遮罩，整张地图直接显示。
- 玩家需要先找到武器，再击败守卫。
- 守卫不再只横向移动，而是在地图可走区域内随机巡逻。
- 守卫会保护钥匙；守卫没有被清除前，钥匙不能被拿走。
- 拿到本关碎片和钥匙后打开出口，进入出口即可通关。
- 第一版可以先用程序绘制的临时场景、武器和守卫效果，后续再逐步替换为正式素材。

## 4. 当前仍保留的页面

- 主菜单：开始游戏、继续游戏、关卡选择、设置
- 探险手册：开始探险、返回菜单
- 设置页：音乐音量、音效音量、切换全屏、返回菜单
- 关卡选择页：可重玩已通关关卡

## 5. 当前需要逐步替换的旧内容

- 旧版钥匙、出口、守卫、沼泽关卡仍是过渡版本，但当前已经加入“武器击败守卫”的核心规则。
- 旧版推箱子相关内容已经不作为后续目标。
- 旧版“只展示剧情的碎片”已经替换为“影响通关的关卡碎片”。

## 6. 后续优先方向

- 自由移动的小女孩控制已开始接入。
- 地图黑色遮罩已取消。
- 武器、守卫保护钥匙、击败守卫后拿钥匙的基础闭环已开始接入。
- 下一步确定每一关的胜利目标，例如找到遗迹出口、点亮核心、抵达营地等。
