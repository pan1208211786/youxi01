# 遗迹小径

这是一个使用 HTML、JavaScript 和 Phaser.js 制作的俯视角森林遗迹冒险游戏。

## 如何打开

直接双击 `index.html`，浏览器会打开游戏。首次打开时需要联网加载 Phaser 游戏框架。
`game.bundle.js` 是浏览器直接运行的合并文件；平时学习和修改请看 `src` 里的分类文件。

如果你修改了 `src` 里的代码，需要双击运行 `tools/build-game.ps1` 一次，它会自动更新 `game.bundle.js`。以后我每次修改代码也会替你更新它。

## 文件大致放在哪里

- `src/scenes`：每一张游戏画面，例如主菜单、关卡、设置。
- `src/entities`：游戏里会移动或有规则的东西，例如女孩和箱子。
- `src/data`：10 关地图的数据，以后加新关主要改这里。
- `src/core`：全局存档、全局状态和通知系统。
- `src/assets`：以后放正式角色、地图、音效图片的地方。

- `tools/build-game.ps1`：把分类源码自动合并成可直接打开的游戏文件，不需要手动复制代码。

第一版为了能马上运行，使用程序画出的卡通图形。正式图片准备好后，只需要替换 `assets` 中的资源，并在 `PreloadScene` 里加载即可，游戏规则代码不需要重写。
